# ternary-permutation

Permutation groups acting on ternary vectors, with orbits, stabilizers, and cycle decomposition.

## Why This Exists

Ternary data (values 0, 1, 2) often has symmetry — features can be permuted without changing meaning, or you need to understand which permutations preserve a structure. This crate provides the algebraic machinery: permutation composition, inverses, cycle decomposition, orbit-stabilizer computation, and the action of permutations on ternary tuples. It generates symmetric groups, computes stabilizer subgroups via Schreier's lemma, and can enumerate the full action on {0,1,2}^n. If you're studying symmetry in ternary codes, investigating permutation-invariant features, or exploring group-theoretic properties of ternary spaces, this is your toolkit.

## Core Concepts

- **`Permutation`** — A bijection on {0, ..., n−1}, stored as an image vector. `perm[i] = j` means element `i` maps to position `j`.
- **Orbit** — The set of elements reachable from a starting element by repeatedly applying generators.
- **Stabilizer** — The subgroup of permutations that fix a given element. Computed via Schreier's lemma.
- **Cycle decomposition** — Expresses a permutation as a product of disjoint cycles. Determines the sign (even/odd) and order.

## Quick Start

```toml
# Cargo.toml
[dependencies]
ternary-permutation = "0.1"
```

```rust
use ternary_permutation::*;

fn main() {
    // Create a permutation: (0 1 2) — a 3-cycle
    let p = Permutation::new(&[1, 2, 0]);
    assert_eq!(p.apply(0), 1);
    assert_eq!(p.apply(1), 2);
    assert_eq!(p.apply(2), 0);

    // Compose and invert
    let q = Permutation::new(&[1, 0, 2]); // swap 0 and 1
    let pq = p.compose(&q);
    let inv = p.inverse();
    assert!(p.compose(&inv).is_identity());

    // Cycle decomposition and order
    println!("Cycles: {:?}", p.cycle_decomposition()); // [[0, 1, 2]]
    println!("Order: {}", p.order()); // 3
    println!("Sign: {}", p.sign()); // +1 (even)

    // Act on a ternary vector
    let v = vec![0u8, 1, 2];
    let w = p.act_on_ternary(&v);
    println!("{:?} -> {:?}", v, w); // [0,1,2] -> [2,0,1]

    // Orbit of element 0 under a set of generators
    let g = Permutation::new(&[1, 0, 2]);
    let orbit = Permutation::orbit(0, &[g]);
    println!("Orbit of 0: {:?}", orbit); // [0, 1]
}
```

## API Overview

### Construction
- `Permutation::new(images)` — Create from an image slice (panics if not a valid bijection)
- `Permutation::identity(n)` — Identity permutation on `n` elements

### Properties
- `p.len()` — Number of elements
- `p.apply(i)` — Image of element `i`
- `p.is_identity()` — Check if identity
- `p.order()` — Smallest k such that p^k = identity
- `p.sign()` — Sign (+1 even, −1 odd)
- `p.cycle_decomposition()` — Disjoint cycles as `Vec<Vec<usize>>`

### Operations
- `p.compose(&q)` — Composition (self ∘ q)
- `p.inverse()` — Inverse permutation
- `p.act_on_ternary(v)` — Permute positions of a ternary vector

### Group Theory
- `Permutation::orbit(i, generators)` — Orbit of element under generated group
- `Permutation::stabilizer_generators(i, generators)` — Stabilizer via Schreier's lemma
- `Permutation::symmetric_group(n)` — All n! permutations of {0, ..., n−1}
- `Permutation::transpositions(n)` — All transposition generators
- `p.generated_group()` — Cyclic group generated by this permutation

### Ternary-Specific
- `p.action_on_ternary_tuples()` — Apply permutation to all 3^n ternary vectors
- `Permutation::index_to_ternary(idx, n)` — Convert flat index to ternary vector
- `Permutation::ternary_to_index(v)` — Convert ternary vector to flat index

## How It Works

**Composition** applies two permutations in sequence: `(p ∘ q)(i) = p(q(i))`.

**Inverse** builds the reverse mapping: if `p(i) = j`, then `p⁻¹(j) = i`.

**Order** is the least common multiple of the cycle lengths (computed exactly in `O(n)`). The order of any permutation of `n` elements divides `n!`.

**Cycle decomposition** traces orbits of individual elements. Fixed points (1-cycles) are omitted. A cycle of length `k` has sign `(-1)^(k-1)`, so the overall sign is `+1` (even) iff there is an even number of even-length cycles. For example `(0 1)(2 3)` — two even-length cycles — is an **even** permutation (`+1`).

**Orbit computation** uses a graph traversal: starting from element `i`, repeatedly apply all generators to discover reachable elements.

**Stabilizer generators** use Schreier's lemma: for each orbit element `o` and each generator `g`, the Schreier generator is `rep(g(o))⁻¹ ∘ g ∘ rep(o)`. These generate the stabilizer subgroup.

## Use Cases

1. **Ternary code symmetry** — Find automorphism groups of ternary error-correcting codes to identify equivalent codes.
2. **Feature permutation invariance** — Compute which feature permutations preserve a ternary classification boundary.
3. **Combinatorial enumeration** — Generate and act on all ternary tuples to count distinct configurations under symmetry.
4. **Cryptography** — Study permutation-based mixing functions in ternary encoding schemes.
